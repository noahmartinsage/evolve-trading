## 2. 市场操纵监控（✅ 自监控已实现）

`server/surveillance.ts` + `GET /surveillance`：

- **SELF_TRADE**：同账户对向成交价差 ≤5bps / 60s 窗口 → 标记
- **ORDER_CHURN**:5 分钟窗口内撤单率 ≥0.8 且提交 ≥20 → 标记
- 全部标记落审计账本（appendEvent），可追溯
- **待补**：跨账户串谋检测（多账户后）、mark-out 事后分析、监管报表导出格式
